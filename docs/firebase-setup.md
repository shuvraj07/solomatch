# Firebase setup

The app targets **Android** for now. Package name: **`com.solomatch.app`**.

## 1. Create the project

1. Go to the [Firebase console](https://console.firebase.google.com/) and click **Add project**. Enabling Google Analytics is recommended.
2. Upgrade to the **Blaze** plan. Cloud Functions and scheduled reminders do not run on the free Spark plan.
3. **Build → Firestore Database → Create database**, in production mode.
   Choose location **`asia-south1` (Mumbai)**, the closest region to Nepal. The
   default Functions region (`Env.functionsRegion`) is the same, which keeps
   latency low. The location cannot be changed later.
4. **Build → Storage → Get started**, in the same region.

## 2. Register the Android app

1. **Project settings → Add app → Android**, package name `com.solomatch.app`.
2. Add the SHA-1 and SHA-256 of every signing key. Google Sign-In fails without them.
   Get them for a machine's debug key with:
   ```sh
   keytool -list -v -keystore ~/.android/debug.keystore -alias androiddebugkey -storepass android -keypass android
   ```
   Each developer machine has its own debug key, so add each one. When you create
   a release keystore, add its fingerprints too, and the Play App Signing key's.
3. Connect the app with the FlutterFire CLI, which generates `lib/firebase_options.dart`
   and adds the Gradle plugins:
   ```sh
   dart pub global activate flutterfire_cli
   firebase login
   flutterfire configure --project=<your-project-id> --platforms=android --android-package-name=com.solomatch.app
   ```

## 3. Enable sign-in providers

**Build → Authentication → Sign-in method**:

- **Email/Password**: enable it.
- **Google**: enable it and set a support email.
- **Facebook**: create an app at [developers.facebook.com](https://developers.facebook.com/),
  add the **Facebook Login** product, then paste its App ID and App Secret into Firebase.
  Copy the OAuth redirect URI that Firebase shows back into the Facebook app settings.
  The Facebook App ID and Client Token also go into the Android app; this is done
  in Phase 1 and covered in `docs/authentication.md`.

## 4. Local emulators

Install the [Firebase CLI](https://firebase.google.com/docs/cli), then run:

```sh
firebase emulators:start          # Auth 9099, Firestore 8080, Functions 5001, Storage 9199, UI 4000
flutter run --dart-define=USE_FIREBASE_EMULATORS=true
```

On a physical phone, also pass `--dart-define=EMULATOR_HOST=<your PC's LAN IP>`.

## 5. Deploy rules and indexes

```sh
firebase deploy --only firestore:rules,firestore:indexes,storage
```

## What lives where

| File | Committed? | Notes |
|---|---|---|
| `lib/firebase_options.dart` | Yes | Generated by `flutterfire configure`. The values identify the project and are not secret. |
| `android/app/google-services.json` | Yes | Same as above. |
| `firebase.json`, `firestore.rules`, `firestore.indexes.json`, `storage.rules` | Yes | |
| `.firebaserc` | Yes | Project alias. |
| Service-account keys | **Never** | |
